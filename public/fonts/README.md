# Geist Sans

`Geist-Latin-Variable.woff2` is the unmodified Latin subset served by the
official Google Fonts API for Geist, normal style, variable weights 400-700.
Only this font file is needed; no italic or monospace fonts are included.

- CSS source: https://fonts.googleapis.com/css2?family=Geist:wght@400..700&display=swap
- Binary source: https://fonts.gstatic.com/s/geist/v5/gyByhwUxId8gMEwcGFWNOITd.woff2
- License source: https://raw.githubusercontent.com/google/fonts/main/ofl/geist/OFL.txt
- Upstream project: https://github.com/vercel/geist-font
- Retrieved: 2026-09-06
- License: SIL Open Font License 1.1; the full copyright and license are in `OFL.txt`.
- Font SHA-256: `9b6f5ff45b278c744b5f379a2c4ecbaf858a842b8eaf82ac8d21b699ca16c608`
- License SHA-256: `1781d2806a07d91c4edf4740b88449fab7d0eadad53f7c351b94cd4d4eb8c00f`

The Google Fonts CSS was requested with a modern Chrome user agent, which
returns WOFF2 and declares `font-weight: 400 700` for the Latin subset.
Use `/fonts/Geist-Latin-Variable.woff2` with normal style and weights 400-700.
